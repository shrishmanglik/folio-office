# Security policy

This project is in early development. There is no supported stable release or promised response SLA yet. Security fixes target the current default branch.

Please report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/shrishmanglik/folio-office/security/advisories/new). Include affected commit/version, minimal reproduction, expected impact and a synthetic sample if needed. Do not post credentials, personal documents or exploit details in public issues.

If private reporting is unavailable, open a public issue requesting a private contact channel without disclosing vulnerability details.

Local files are plaintext, not encrypted. The engine is a local process, not a sandbox. Import/export paths are supplied by the caller. Treat imported files as untrusted and keep backups before testing conversions.
